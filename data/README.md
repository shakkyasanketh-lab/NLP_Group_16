# Dataset

## PhishGuard AI — Phishing Email Dataset

**Source:** https://www.kaggle.com/datasets/naserabdullahalam/phishing-email-dataset

**File to download:** phishing_email.csv (~82,500 emails)

**How to set up:**
1. Download the dataset from the link above
2. Extract and place `phishing_email.csv` in this `/data` folder
3. The file is excluded from Git due to size — download manually

**Dataset Info:**
- Total emails: ~82,500
- Phishing: ~42,891
- Legitimate: ~39,595
- Columns: email_text, label (1=phishing, 0=legitimate)
